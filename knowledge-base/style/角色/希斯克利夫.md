## 一句话定位

**伦敦东区混混出身的暴力直球汉**：用拳头、嗓门和反问句代替论证，脏话与俚语密度全队最高（`bloody` 4.0% 行、`ain't` 4.2% 行、吞音 `-in'` 4.7% 行），
但**官方中译刻意"去脏化"**——只保留粗粝的口语节奏，不用性/排泄类脏字。他的敬称使用率是全队倒数第三（0.22% 行，仅高于良秀 0.00%、奥提斯 0.17%），
对但丁有专属绰号"钟表头"。

## 语气与语域

- **市井口语、挑衅、外放。** 英语侧缩合与吞音密度全队第一：`n't` 21.8% 行、`'em` 2.6% 行、`ain't` 4.2% 行、吞掉 g 的 `-in'` 4.7% 行。
  - EN: Uh... ain't these memories for Clockhead's eyes only? Why can we see it, too?
    CN: 那个……那不是钟表头才能看见的记忆吗？怎么我们也看到了？
  - EN: You're full o' beans today, ain't ya?
    CN: 你今天心情不错嘛。
- **脏话密度全队最高，但中译整体降档。** 英语侧 `bloody` 4.0%、`hell/damn` 4.7%、`sod` 1.0%、`shit/shite` 1.7%、`bastard` 1.3% 行；
  中译"妈的/靠/操/混账/混蛋/该死"类词每千字 **2.65 次**，是以实玛利（0.47）的 5.6 倍、辛克莱（0.19）的 14 倍。

  （口径：`妈的|混蛋|混球|混账|该死|靠|嘁|啧|滚|shit|fuck`。他是第 2 名良秀的 2.1 倍。）
  但含 `bloody|blimey|bugger|sod` 的 158 行里，绝大多数被降级成"呼/不是/啊/可恶/靠"，甚至整句省略：

    CN: 呼，真难缠。
  - EN: Blimey, what the hell is...
    CN: 可恶，又怎么了……

    CN: 妈的……瞧瞧那捕鲸枪的大小。
  **结论：粗，但不脏到出戏。** 中译实际用词上限是"妈的/混蛋/混球/嘁/啧/滚/靠"这一档。
- **反智式讥讽**是他最稳定的语域特征：遇到"聪明人/有钱人"就切换成阴阳怪气的假敬语或贬称。
  - EN: …Got well emotional and gobby, eh, Ms. Cleveress?
    CN: ……眨眼间变得情绪化了很多嘛，万事通小姐。
  - EN: Hah! Thought we’d be fooled by a bunch of big fancy words?
    CN: 哈！你以为把挺像那么回事的词语一股脑并起来就能忽悠到我？
- 极少数真正的重度脏话被"性格化改译"而非直译，例如 `fuck`：
  - EN: …For fuck’s sake, woman!
    CN: ……啧，你！

## 句法特征

- **均英词 12.0（三人最短），均中字 19.5（三人最短）**——短促。
- **反问/质问收尾密度全队最高**：英文侧 `?` 41.6% 行，中文侧行尾"？"28.0%；行尾"！"10.4%。两者合计 38.4% 的台词以"质问或爆发"结束。
- **附加疑问句（tag question）是他的句法指纹**：`yeah? / eh? / innit?` 共 **97 行**。
  - EN: So this is another Lobotomy Corp. branch, innit?
    CN: 没错吧？脑叶公司支部。
  - EN: It's all mucked up with blood. Now that's a right terrifyin' look, innit...?
    CN: 上面到处沾的都是血，真是一团糟。这样子看着还有点恐怖……
- **祈使句 + 即时行动**：
  - EN: Oi, bite into it!
    CN: 喂，咬一口试试！
  - EN: Oi! Take this rope, now! Quit faffin' about and tie it 'round your waist!
    CN: 喂！磨蹭什么呢，还不快拿去绑上！
- **长句只出现在"讲自己帮派往事"时**（最长台译为 72 字，讲 Matthew 与死兔帮），此时语句反而连贯流畅、逻辑连接完整——他不是不会说长句，只是不想用来论证。
  - EN: And guess what, turns out <i>that</i> pub was the secret hideout where the opposing Syndicate was holed up. They were crowdin' around the gaffer, running their mouths about how they'll kill him and put an end to the Dead Rabbits. That's when we came storming in and had them surrounded instead.
    CN: 结果我们去到的地方是之前没人听说的敌人的秘密基地。那些人还围着大哥，说只要杀了你死兔帮也就活到头了，到头来反而被我们给包围了，哈。

## 称呼他人的方式

- **但丁 →「钟表头」（38 次）**，全队唯一如此称呼的人。另有 4 次"时钟"、4 次"经理"。
  - EN: It's your job, clockhead. Fish her back up. The lass is sinking.
    CN: 钟表头。把那沉溺的家伙捞上来是你的工作。
  - EN: ... Oi, Clockhead. One clock-turnin' coming right up. This'll be the last one in a while, so just take one for the team, alright?
    CN: ……钟表头。一时半会也没什么要救人的活，今天就转他个一人份的吧。没关系吧？
- **女性 → `lass`（63 行）/ `girl`（4 行）**。中译常省略称呼，或改"你 / 这家伙"，**不逐字译成"姑娘"**：
  - EN: Lemme see that, lass. Hm... these look like coins, but aren't actual cash. So how are these 'lifetokens' again?
    CN: 让我看看……嗯，模样像是铜钱，但并不是真正的钱啊。这东西怎么就成了生命之价值了？

    CN: 你这家伙当时明明被蓝色的镰刀砍死了几十次，还这么开心吗……？
  - EN: Wha— *cough* I was clearly jokin', lass. You didn't have to be so cross about it.
    CN: 什……咳，你怎么说话这么尖锐啊？我就开个玩笑……
- **男性 → `mate / lad / bloke / git`**：
  - EN: Bloody hell, mate, you could've led with that... *cough* Ow, I think some of that went down the wrong pipe.
    CN: 别突然来那么一下啊……咳。啊真是的，喉咙痛。
  - EN: You've a way of mincin' words, don't you? Thanks, lad.
    CN: 你这说法换得挺好……喂，谢谢。
- **帮派前辈 → `Boss / bossman / 형님` →「大哥」（高度一致，无例外）**：

- **中年男性 → `아저씨` →「大叔」（也作"虫子叔"这类绰号化变体）**：

## 自称

- **「我」**（29.0% 行）。**默认绝不用"俺/咱/老夫"**：1854 行中仅 5 行出现"咱/俺/老子"。
- **"老子"只在极度暴怒时偶发（3 例）**，不可常规化：
  - EN: Bloody hell! Why is the damn fry pan heated? It almost grilled me dead!
    CN: 妈的！为啥这个破煎锅这么烫？！烫死老子了！
  - EN: Wha… Who the hell was that?! I almost kicked it!
    CN: 是……是哪个混蛋！老子差点就没命了！
  - EN: Proper trifling twits, tch. Who are you telling me to kneel?

## 该角色容易翻错的点

1. **把 `bloody/hell` 一律翻成"他妈的/操"** → 过脏出戏。官方 158 行含此类词，绝大多数降级为"呼/不是/啊/可恶/靠/妈的"。
   - EN: Gah, bloody persistent, innit?
     CN: 呼，真难缠。
2. **给他加"先生/小姐"敬称** → 破坏人设。他 1854 行里只有 4 行出现敬称，且多为反讽。
   > 陷阱来源：韩文里他的 `씨` 有 18+ 次其实是脏话 `아이씨 / 야이씨`（相当于 damn），不是敬称。中译正确地没有照搬。
   - EN: Blimey, what the hell is...
     CN: 可恶，又怎么了……
3. **把"钟表头"改写成"但丁经理/但丁先生"** → 抹掉他唯一的固定绰号（38 次）。
4. **把 `lass / mate / lad` 逐字译成"姑娘 / 伙计 / 小子"** → 中文生硬。官方多省略或改"你 / 这家伙"。
   - EN: Bloody hell, lass! Don't you know what happened the last time I crossed it?
     CN: 喂，你不知道上次我跨过那条线的时候发生了什么吗？
5. **把缩合/吞音翻成书面语**（"我不认为""那是什么东西"）→ 丢失市井语域。要落在"不就好了吗/呗/啊/什么玩意儿"这一档。
6. **误以为"他没文化所以只会短句"** → 讲帮派往事时他的长句（最长 72 字）连贯完整。
7. **`harpoon` 译名不统一**：他的台词里同时出现"捕鲸枪""鱼叉"（以实玛利侧还有"捕鲸叉"），新文本需按术语表统一。

## 翻译操作清单（Do / Don't）

**Do**
- 用**短句 + 祈使句 + 反问/附加疑问收尾**（"…不就好了吗？""…对吧？""…不是么？"）。
- 脏话只取**"妈的 / 混蛋 / 混球 / 嘁 / 啧 / 滚 / 靠 / 可恶"**这一档；`bloody` 允许虚化为"呼 / 啊 / 不是"。
- 中文句首用**"喂"**承接 `Oi`。
- 保留固定称呼：**钟表头 / 大哥 / 少爷 / 小少爷 / 天才小姐 / 万事通小姐 / 四眼仔 / 凯茜 / 马修 / 死兔帮**。
- 语气词落在**吧 / 啊 / 呢 / 干嘛**，允许"咯"。
- 威胁句动作化：**揍一顿 / 打爆脑袋 / 脑袋开花**。

**Don't**
- ✗ 不用"先生 / 小姐 / 女士"（反讽除外）。
- ✗ 不用"俺 / 咱 / 老夫"作默认自称；"老子"仅限暴怒单点。
- ✗ 不逐字搬 `blimey / sod / git / innit`。
- ✗ 不把 `bloody` 全部实译成脏话。
- ✗ 不用长复合句、书面连接词（"因此 / 综上所述 / 基于此"）。
- ✗ 不用"您"（他 1854 行里只出现 2 次）。
