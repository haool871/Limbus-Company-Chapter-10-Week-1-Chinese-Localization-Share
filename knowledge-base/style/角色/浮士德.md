## 一句话定位

**全知视角的冷静分析师**：句子是罪人中最长的（均英词 15.4、均中字 24.1，全队第一），情绪波动却是最小的（行尾「！」仅 0.6%）；
最大的标志是**用第三人称「浮士德」自称**（184 行，占 7.9%），以及一套完整的**敬称体系**（先生 72 次／小姐 53 次）。
她的语气不冷漠，而是**把一切（包括自己）当作可观测、可分析的客体**。

## 句法特征

- **全队最长的句子**：均英词 15.4（李箱 13.5／堂吉诃德 13.5）、均中字 24.1；EN 长度 p90 = 29 词。
- **长句在中文里被拆短、压缩**，不是逐字对译成一个大长句。典型例子是她那段又长又绕的纠正：
  - EN: `I cannot comprehend what you are attempting to take back. Your rather abstract reference to this unknown concept that you supposedly mentioned 'earlier' is hardly clarifying. Anyway, allow me to list the specifications of screws used in Mephistopheles' construction that make this creation so impressive. First—` / CN: `"刚才"是一个相当广阔的时间范围，因此浮士德无法理解你具体想要收回哪些发言。相反，浮士德可以详细描述一下梅菲斯托费勒斯的完美之处，例如这颗螺丝钉的规格。` [StoryData/E042X.json#25]
  - EN: `There is a possibility that she will be unable to return to her current self no matter how many times Dante's clock is rewound.` / CN: `那么无论经理的时钟回拨多少次……她都有可能无法回归成如今的堂吉诃德小姐。` [StoryData/S922B.json#60]
- **条件句 + 让步句密集**（`If... then...` / `However...` / `Though...`）：`however` 在她的英文里出现 94 次。
  - EN: `If they are in fact new to Miss Yuri, then these might be another type of entity derived from Abnormalities... Perhaps a new species.` / CN: `如果尤莉小姐确实没见过它们，那这些个体可能是源于异想体的其他的……或许也有可能是新的种类。` [StoryData/1D102A.json#12]

- **短促的独立应答**是她另一种句法：`不。`（多连发）／`没错。`／`了解。`／`原来如此。`／`正是如此。`
  - EN: `No.` / CN: `不。` [StoryData/E618B.json#24]（同场景 #26、#28 连续三句）
  - EN: `Correct. Do you recognize when this was?` / CN: `没错。各位知道此处是哪个时间段吗？` [StoryData/1D301B.json#25]
  - EN: `... I see.` / CN: `……原来如此。` [StoryData/E080X.json#59]
  - EN: `... Understood. Given that the expense is made to facilitate this operation, the lack of prior budgeting should not pose a problem.` / CN: `……明白了。既然是为了顺利完成工作而进行的支出，应该没有问题。` [StoryData/E921B.json#55]
- **极简命令式**：`Go on. / Speak. / Do ask. / Do speak.` → 一律「请讲／请说」。
  - EN: `Go on.` / CN: `请讲。` [StoryData/P10302.json#1]
  - EN: `Speak.` / CN: `请说。` [StoryData/S625B.json#5]
  - EN: `... Do speak.` / CN: `……请说。` [StoryData/S907B.json#115]

## 该角色容易翻错的点

1. **第三人称自称不许改成「我」。** `Faust knows it all.` → `浮士德无所不知。`，不是「我无所不知」。只有记录体／人格剧情允许（见上）。
2. **`Herr / Miss / Ms.` 不是德语梗，是敬称层。** `Herr Gregor` → 格里高尔先生、`Miss Yuri` → 尤莉小姐、`Ms. Ahab` → 亚哈女士。别音译成「赫尔」。
3. **英文没写敬称也要补。** `Gregor` → 格里高尔先生、`Ishmael` → 以实玛利小姐、`Kira` → 绮罗小姐。这是官译一贯做法（源自韩文敬称），漏掉就丢了她一半的性格。
4. **「小姐／女士」按对象区分**：她对女性同僚习惯用「小姐」（堂吉诃德小姐、以实玛利小姐、绮罗小姐、奥尔佳小姐），对亚哈、Malkuth 等年长／地位高者用「女士」。李箱则几乎只用「女士」——不要串。
5. **不要把她的长句照搬成长中文。** 中文官译平均 24.1 字，且把 EN 的多层从句拆开重组；必要时用「因此／相反／简而言之」提接。
6. **`indeed` 不等于「的确如此」。** 官译按位置分流为「确实／没错／正因如此」；`Correct.` → 「没错。」，`Precisely.` → 「正是如此。」。
