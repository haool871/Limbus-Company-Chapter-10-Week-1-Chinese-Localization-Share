# 格里高尔 / Gregor  说话风格指南

> **语料口径**：`StoryData` 全 941 个剧情文件中，kr `model=그레고르` 且 en/cn 均非空的台词 **1594 句**。
> 量化指标取自 `data/voice_stats.json`，并已用 `tools/voice_profile.py` 的同一口径复算。
> 引用一律用方括号标注出处（`文件名` + `#` + `id`），可用 `python3 tools/pm_lib.py show StoryData/<文件名>` 逐条复核。
> 口径说明：`每100句` = 该串在全部 CN 台词中出现次数 × 100 ÷ 台词行数；`……` 按 `…` 字符计，
> 故一个「……」记 2 次（`data/voice_stats_exact.json` 把「……」记 1 次、行数口径略窄，数值约低一半）。

## 一句话定位

**疲惫的中年老兵**：用一声「呼」把叹气、抽烟、苦笑、欲言又止全部咽下去。句法上他是四人中**最"没脾气"的**——
感叹号只有 6.7 次/百句（罗佳 18.2 / 奥提斯 16.0 / 但丁 9.3），省略号却是 159.8 次/百句（四人最高）。
对谁都用「老兄 / 小姐 / 先生 / 经理兄」这种**不设防的平辈亲切**，自嘲是他与世界相处的默认姿态。

## 语气与语域

- **低能量的口语，絮叨而温和。** 几乎不喊叫（`！` 6.7 次/百句，四人最低）；情绪出口是叹词而非感叹号。
  - EN: `*puff*` → CN: `呼……` `[E908B.json#53]`
  - EN: `*sigh*` → CN: `呼……` `[E908B.json#123]`

## 句法特征

- **均英词 13.2 / 均中字 21.3**，长度中等；但**句子拖尾、插话式补充多**，靠「……」「不过」「虽然」把话拉长。
- **让步—转折是他的主力句式**：`虽然` 3.1 / `不过` 2.1（次/百句）。
  - EN: `Not at all, manager bud. Look, they haven’t all mutated in the same pattern, like into an insectoid form for example.` → CN: `完全不一样吧。首先他们看上去就都不像是虫子吧，经理兄……` `[E719B.json#22]`
  - EN: `Ah, well... I would've had to share this with Manager Bud or the rest of you fellas sooner or later, so I don't really mind. But...` → CN: `哎呀……反正这些话迟早也得对经理和大伙说，所以也没关系啦……` `[E908B.json#108]`
- **惯用「……吧」「……的话」把断言软化成猜测**（`吧` 15.1 次/百句，仅略低于罗佳）。
- **列举时用「像是……之类的」**（`之类的` 0.7 / `什么的` 0.5 次/百句）。
- **自我打断**：`那个……` / `怎么说呢` / `呃`（`怎么说呢` 0.3 次/百句）。
  - EN: `That’s uh… you know. You know how it is. Be proud of who you are, all that philosophy stuff.` → CN: `那个……怎么说呢，就这么回事呗。从哲学上来讲就是，展露本真的自我就好。` `[E803B.json#56]`
- **无奈的自问式疑问**（`？` 38.1 次/百句，但多为自问，不是质问）：
  - EN: `What’s with everyone getting so anxious to get picked here?` → CN: `为什么大伙都这么紧张呢？` `[E704A.json#56]`

## 该角色容易翻错的点

1. **「呼」不是单一映射，要按英文侧分流。** `*puff*/*sigh*/Haah/Puff/Phew/Man` → 「呼……」；`Whew` → 「呼呜……」；`Oh boy/Ah shoot/Oh damn` → 「哎呀……」；`Yawn` → 「呼啊」。见上表。
2. **不要把他写成开朗大叔或毒舌。** 他的底色是**疲惫 + 无害化自嘲 + 和稀泥**。感叹号 6.7 次/百句是四人最低——这是最硬的量化证据。
3. **`Manager Bud` 必须是「经理兄」**，不是「经理」「老板」「老哥」。这是零协会给他的专属口吻标记（35 次）。
4. **他不说「执行经理」**（在他的 1594 句里 0 次）。若新文本需要全称，按零协会既有做法用「经理」或偶发的「但丁经理」。
5. **`□□小姐 / □□先生` 是零协会的既有社会称谓**（尤莉小姐、阿雅小姐、浮士德小姐、索德小姐、东朗先生），不是亲密称谓，也不是敬语过度；不要换成「女士」「夫人」「老妹」。
6. **他的烟是"停顿道具"而非"角色卖点"**：官方只把 `*puff*` 处理成「呼……」，不加「他点起一支烟」之类的补足叙事。
7. **战争专名照抄既有译名**：Smoke War → **烟霾战争**；`war` → 战争。他谈战争时是**疏离的**，不要翻成热血回忆：
  - EN: `Look, the war ended a decade ago. Haven't any of you learned to move on from playing soldiers?` → CN: `你看，战争早在十年前就结束了。你还没从军队过家家中清醒过来吗？` `[1D202B.json#6]`
8. **他的自嘲不能翻成自卑或抑郁**：官方用「哎呀 / 呼 / 嘛」卸力，保持轻。
9. **`Sinners` → 罪人**、`Fixer` → 收尾人、`Finger` → 手指（组织名，如「手指干部」），均按 `terms/glossary.tsv`。

## 翻译操作清单（Do / Don't）

**Do**

- 英文侧见到 `*puff*` / `*sigh*` / `Puff` / `Haah` / `Phew` / `Man` → 起手「呼……」。
- 见到 `Oh boy` / `Ah shoot` / `Oh damn` → 起手「哎呀……」。
- 保留**长句 + 拖尾省略号**的节奏；一个英文长句在中文里可以保持长，并在末尾用「……」收。
- 称谓照抄：经理兄 / 老兄 / ○○小姐 / ○○先生 / 大伙。
- 用 `虽然`、`不过`、`反正`、`之类的` 做让步与软化。
- 谈过去时保持"没什么大不了"的疏离语气。

**Don't**

- ✗ 给他的话加感叹号（`！` 密度必须保持四人最低）。
- ✗ 把 `Manager Bud` 改成「经理 / 老板 / 老哥」。
- ✗ 把 `Huh` 译成「咦 / 哦 / 呃」——官方口径是「哈」。
- ✗ 给他加 `~`。
- ✗ 把 `*puff*` 扩写成叙事（"他吐出一口烟"）。
- ✗ 把自嘲翻成真正的自我否定（"我真没用"）。
- ✗ 让他用「本人 / 在下 / 您」等敬语体系。
