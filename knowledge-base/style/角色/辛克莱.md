## 一句话定位

**成长中的少年**：**全队敬语密度最高的角色**（"先生/小姐/女士"12.07% 行，12 名罪人中排名第一；"您"4.2% 行），
同时全队最犹疑（推测词 5.06/千字、行尾省略号 35.1% 行、英文口吃 11.7% 行）。
**省略号、口吃顿号、"您"**是他的三个指纹。随剧情推进，后期出现更坚定的短句，但基线仍是"怕说错话"。

- **犹豫与不确定是常态**：每千字推测类词（大概/应该/也许/说不定/似乎/好像）**5.06**，三人最高（以实玛利 3.10、希斯克利夫 1.30）。

## 句法特征

- **均英词 10.4 / 均中字 18.3，三人最短**——短句多、常被自身打断。
- **口吃 / 自我打断是最强句法指纹**：英文侧 `W-wait / I-I / N-No` 型出现于 **11.7% 行（197 行）**。
  中译**用顿号"、"复制音节重复**，而不是用省略号：
  - EN: W-wait! He's just cremating it!
    CN: 等、等下！他只是在把它火化！
  - EN: N-No… I don’t want to show my memories, they, they’re…
    CN: 不、不要……我不想让你们看到，我、我的记忆……
  - EN: M-manager, you're up! You were out cold for a while, so we were all pretty worried.
    CN: 经、经理！您终于醒了！您醒不过来大家都很担心您呢！
  注意分工：**"、"承担口吃**（"等、等一下"），**"……"承担语尾中断/迟疑**（"我不想让你们看到……"）。两者不可互相替代。
- **英文侧的单词重复型口吃也被归一为汉字口吃**：
  - EN: N-No… I don’t want to show my memories, they, they’re…
    CN: 不、不要……我不想让你们看到，我、我的记忆……
- **省略号收尾比例全队最高**（行尾 35.1%、含"……"69.9%）：
  - EN: W-Why our basement, exactly?
    CN: 为、为什么要去我家的地下室？
  - EN: W-we're a different candidate's clan.
    CN: 我……我们是其他的候选人。
- **自我确认式疑问句**（"…对吧？""…吧？"）：
  - EN: R-right? I know I only have this vague feeling to go on, but... it seemed that they really wished the best for Hongyuan.
    CN: 对、对吧。虽然只是根据之前所见……但他们看起来是真心在乎鸿园。
  - EN: W-we're going our separate ways, just like that...? 
    CN: 就、就这样分开真的没问题吗？
- **列举式长句**（最长台译 86 字，结构是"谁谁会怎样"的清单）——他紧张时会一口气把可能性全列出来：
  - EN: W-well, who else besides me would ever go along with these lesson plans? Don Quixote's going to ditch the classes out of boredom, same goes for Rodya, and... Outis'll try to take over the classes... not to mention what it'd be like to have Heathcliff here, and...
    CN: 那、那个……能陪着一起上这些课的人就只有我一个了。堂吉诃德小姐会因为无聊而翘课的。罗佳小姐也会如此……奥提斯女士会变成上课的那个人……希斯克利夫先生就更不用说了……还有……

    CN: 我很害怕，怕得不得了，我甚至想要立刻扔下这把剑逃离，但是……

- **完全不用"咱 / 俺 / 老子"**（每千字 0.00）。
- **自称常被口吃切碎**：
  - EN: I—I…

## 该角色容易翻错的点

1. **漏掉"先生 / 小姐 / 女士"——最大的陷阱。** 英文版丢掉了他 62% 的敬称（153/247 行），中译保留率 84%。只跟英文走会系统性丢失少年敬语人设。
   - EN: Weren't you the one who snatched it away...?
     CN: 不是希斯克利夫先生自己拿去的吗……？
   - EN: Heathcliff, if you don't take it back... I don't think she's ever going to stop...
     CN: 希斯克利夫先生，如果你不收回那句话……我想她不会停下来的……
2. **把口吃翻成省略号**（"等……等一下"）。官方用**顿号**："等、等一下"；"……"另有一职。
   - EN: W-wait for me!
     CN: 等、等等我！
3. **给德米安加"先生"。** 他对德米安直呼其名，这是全篇唯一的敬称例外。
   - EN: Demian, have you been to the Outskirts?
     CN: 德米安，你去过郊区吗？
4. **敬语体系崩塌**："您"只给但丁与长辈（4.2% 行），对同辈罪人用"你 + 先生/小姐"。两者不在同一句混用。
   - EN: R-right? I know I only have this vague feeling to go on, but... it seemed that they really wished the best for Hongyuan.
     CN: 对、对吧。虽然只是根据之前所见……但他们看起来是真心在乎鸿园。
5. **把他的成长写成单纯的胆怯。** 后期有明确变坚定的台词，不能一律翻得吞吞吐吐。
   - EN: That’s it, I’m not going to hesitate to make myself heard again… This time, I want to be courageous... with your help, Don Quixote...
     CN: 我、我也不能总是犹豫不决、一言不发啊……趁着这个机会，我要鼓起勇气和堂吉诃德小姐一起……
6. **省略号过疏**：他 69.9% 的台词含"……"，是三人最高；省略过多会丢掉他"话说不完"的质感。
7. **用"嘛 / 啦"等俏皮语尾**（他两个词都只有 0.2% / 0.1%）。
8. **把惊慌的"！"翻成攻击性的吼叫**。他的高声调来自害怕，不是威吓。

## 翻译操作清单（Do / Don't）

**Do**
- 用**短句**，并在迟疑处保留**"……"**（他 69.9% 的台词含省略号）。
- 口吃一律用**顿号**："等、等一下""我、我们""对、对吧""经、经理""不、不用了"。
- 对全体罪人与长辈补出**"○○先生 / ○○小姐 / ○○女士"**；对但丁用**"经理 / 但丁经理"+"您"**。
- 保留**推测词**：大概 / 好像 / 应该 / 说不定 / 似乎。
- 保留**"请 / 抱歉 / 对不起 / 谢谢您"**。
- 惊慌处允许连续的短促感叹（"肯、肯定快要爆炸了？！"）。

**Don't**
- ✗ 不写裸名"希斯克利夫 / 堂吉诃德 / 良秀"——必须带"先生/小姐"。
- ✗ 给**德米安**加"先生 / 小姐"。
- ✗ 用"……"代替口吃顿号。
- ✗ 对同辈罪人用"您"。
- ✗ 用"咱 / 俺 / 老子"。
- ✗ 用"嘛 / 啦"等洒脱语尾。
- ✗ 把惊慌翻译成凶悍；不要连续使用"！！"。
- ✗ 不要通篇胆怯——成长后的决心句要译得干净利落。
