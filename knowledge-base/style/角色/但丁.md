# 但丁 / Dante  说话风格指南

> **语料口径**：`StoryData` 全 941 个剧情文件中，kr `model=단테`（2515 句）与 `model=단테2`（260 句，
> Canto V 大湖篇专用变体）且 en/cn 均非空的对齐台词，共 **2775 句**。
> 量化指标取自 `data/voice_stats.json`，并已用 `tools/voice_profile.py` 的同一口径复算。
> 引用一律用方括号标注出处（`文件名` + `#` + `id`），可用 `python3 tools/pm_lib.py show StoryData/<文件名>` 逐条复核。
> 口径说明：`每100句` = 该串在全部 CN 台词中出现次数 × 100 ÷ 台词行数；`……` 按 `…` 字符计，
> 故一个「……」记 2 次（`data/voice_stats_exact.json` 把「……」记 1 次、行数口径略窄，但丁为该口径下 2758 句）。

## 一句话定位

**失忆的"钟表头"经理**：他对外**发不出人声**（别人只听见滴答声），因此剧情里他的台词**几乎全部是 `< >` 包起来的内心独白**。
平均句长四人最短（均英词 8.4 / 均中字 16.4），靠极短句、拖长的省略号和大量疑问句承载"被推着走"的视角；
一旦需要下决定，语气又会突然干脆（`出发吧。` / `够了，各位。`）。

## 语气与语域

- **内心独白体，不是一个"说话"的角色。** 在 2820 条 `단테` 记录中 EN 有 2811 条以 `<` 开头；
  CN 缺失 62 条，余下 2758 条里 **2751 条（99.7%）以 `<` 开头**，仅 1 条例外（见"容易翻错"第 5 条）。
  - EN: `<The star... This one won’t hurt, right?>` → CN: `<星星么……这不会疼吧？>` `[1D104B.json#4]`
  - EN: `<... Where’d its corpse go, anyway? I’m pretty sure that attack did it in...>` → CN: `<……但是，异想体的尸体去哪了？刚刚应该杀掉它了吧……>` `[1D105A.json#8]`
- **"我说的话别人听不见"是他的核心设定，译文要把它保留成角色的日常感，而不是悲情。**
  - EN: `<I’d like to say “Hi, nice to meet you”... but I don’t suppose he can hear what I’m saying.>` → CN: `<你好……像这样，即便问好也只能听见滴答声吧。>` `[E704B.json#20]`
  - EN: `<I don't think he'll hear anything but ticking noises from me... Can you read this, Meursault?>` → CN: `<我说话的声音滴答滴答的……默尔索，能请你来读吗？>` `[E714B.json#79]`
  - EN: `<I disagree. You probably can't hear a thing I'm saying... but I still do.>` → CN: `<不会是那样的。不过反正这话在你耳中也不过是滴答声而已。>` `[S646B.json#21]`
  - EN: `<Tick-tock.>` → CN: `<……滴答。>` `[E519A.json#6]`
- **语域中性偏低、自我怀疑，但不下沉。** `！` 9.3 次/百句、`？` 39.1 次/百句，都比罗佳低一档；
  很少用语气词（`啊` 11.9、`吧` 10.6、`呢` 3.3），也不说粗话。
- **决心句短而干脆**（这是他与"犹疑的内心独白"之间的对比）：
  - EN: `<Let's get going, then.>` → CN: `<出发吧。>` `[E053X.json#94]`
  - EN: `<Guys. Enough.>` → CN: `<够了，各位。>` `[E405A.json#91]`
  - EN: `<Well, let's go check it out right now.>` → CN: `<马上出发吧。>` `[E063X.json#78]`

## 句法特征

- **均英词 8.4 / 均中字 16.4——四人最短。** 英文一两句的内容，中文常压成 8–12 字。
  - EN: `<So... this is the place?>` → CN: `<所以……到地方了？>` `[S506B.json#2]`
  - EN: `<... Let's go.>` → CN: `<……走吧。>` `[E063X.json#162]`
- **`<>` 是硬性格式约定**：`<` 紧贴第一个字，`>` 紧贴最后一个标点，中文标点全部在括号内。
  - EN: `<These bugs aren’t so bad after the last floor’s Abnormality. Don’t want to see anything like that ever again.>` → CN: `<反倒是虫子更好些。我不想再遇见像之前那一层的异想体之类的东西了。>` `[1D301B.json#1]`
- **英文句首的语气词有稳定的中文对应**（实测统计，样本 ≥3）：

  | EN 句首 | 官方 CN | 实测次数 |
  | --- | --- | ---: |
  | `Oh` | 啊 | 30 |
  | `Ah` | 啊 | 21 |
  | `Huh` | 嗯 / 啊 | 13 / 7 |
  | `Hmm` | 嗯 | 11 |
  | `Well` | 那 | 9 |
  | `Then` | 那 / 那么 | 8 / 8 |
  | `So` | 所以…… / 那 | 7 / 6 |
  | `Wait` | 等等 / 等一下 / 等下， | 5 / 3 / 3 |
  | `Okay` | 好吧 | 3 |

  - EN: `<Oh. Hey, Meursault.>` → CN: `<啊，是默尔索小朋友啊。>` `[E003I1.json#30]`
  - EN: `<Huh...? Wait―!>` → CN: `<嗯……？等下……！>` `[1D105B.json#13]`
  - EN: `<Hmm? Oh, yeah.>` → CN: `<嗯？啊，这样啊。>` `[1D203B.json#82]`
- **`好吧……` / `那么……` / `总之……` 三件套**是他转向下一步的固定动作：
  - EN: `<Alright... I did as you asked, Faust.>` → CN: `<好吧……我照你说的做了，浮士德。>` `[E064X.json#0]`
  - EN: `<Sure...>` → CN: `<好吧……>` `[5D106B.json#44]`
  - EN: `<Then...>` → CN: `<那么……>` `[E050X.json#21]`
  - EN: `<Well, then...>` → CN: `<那么……>` `[E601B.json#87]`
  - EN: `<Right... so it all comes down to my choice, huh. Three Sinners...>` → CN: `<那么……应该由我来……选择这3个人吗……>` `[E604B.json#51]`
  - EN: `<Why don't we leave for now? We can always come back here once we uncover more evidence.>` → CN: `<总之先回去吧？等找到证据之后再来……>` `[E610A.json#47]`
- **结巴式重复用「、」断开**，是他受惊/迟疑时的标记：
  - EN: `<H-hey, Outis... you know that's not at all what I meant. I just thought that maybe we needed someone skilled and experienced like you to effectively manage the remaining Sinners while we're—>` → CN: `<奥、奥提斯……不是你想的那样，毕竟剩下来的这些罪人们需要一个能够有效管理他们的人……>` `[E604B.json#84]`
  - EN: `<W-wait, is that what she is to you?!>` → CN: `<是、是这样吗？！>` `[E503B.json#109]`

## 自称

- **「我」18.4 次/百句、「我们」9.1 次/百句——四项中最低**（罗佳 28.0 / 26.7 / 20.9）。
  他的独白以"观察与疑问"为主，不是自我陈述。
- **提到职务时，正式自我介绍用「执行经理」，泛指职责用「经理」**——与奥提斯同一套既有译法：
  - EN: `<... Name's Dante. I'm their manager.>` → CN: `<……我是但丁。这些人的执行经理。>` `[E728B.json#10]`
  - EN: `<I’m Dante, Manager at Limbus Company. I know I'm late, but... thanks for saving my bacon.>` → CN: `<我是但丁，边狱公司的执行经理。虽然有些迟了……但是谢谢你救了我。>` `[PC01B.json#82]`
  - EN: `<Because I am their Manager.>` → CN: `<因为我是执行经理。>` `[5D302B.json#51]`
  - EN: `<Because I'm your manager. Bringing you back to your paths is what I do.>` → CN: `<将你们带回原本的道路，是我作为经理的职责所在。>` `[S635A.json#34]`
- **`<Manager?>` → `<经理？>` 是他在确认别人对他的称呼**，不是他在称呼别人——这是最容易误判的一句：
  - EN: `<Manager?>` → CN: `<经理？>` `[S002B.json#51]`
  - EN: `<You mean… as the manager?>` → CN: `<你是说……执行经理的工作？>` `[S002B.json#153]`
- 他没有敬语自称（`本人` 0.0、`在下` 0.0），也不用「咱」（0.0）。

## 该角色容易翻错的点

1. **⚠️ 先看 `model` 字段，区分"但丁本人"与"旁人转述"。** 只有 kr `model=단테` / `단테2` 才是但丁自己的台词。
   `钟表头`（68 次）绝大多数出自**希斯克利夫**（38 次）之口，是别人对他的称呼；
   `5D103B.json#34` 的 `这个钟表头的船员一直都在滴答滴答的。` 出自 스타벅（Starbuck），`E001X.json#56` 出自 히스클리프2——
   **不要把这些句子翻成但丁的第一人称口吻，也不要加 `<>`。**
2. **`<>` 必须保留**，且中文标点写在括号内（`<好吧……>` 而不是 `〈好吧……〉`、也不是 `<好吧……`）。
   全语料只用半角 `<` `>`。
3. **`■` 不是乱码**，是"被屏蔽 / 不可理解"的词。数量可以按中文长度略作调整，但**不可补出实词**，也不可整句删掉。
4. **`Meursault` → 默尔索、`Faust` → 浮士德、`Ryōshū` → 良秀**，按 `terms/glossary.tsv`；但丁口中一律全名。
5. **既有译文有一处格式瑕疵，不要模仿**：`[E003I2.json#87]` EN 为 `<The other classes are practically finished. And I don't mean that in a good way. At this point, honestly, you'd win even if you served raw, unseasoned chicken just like that.>`，
   CN 却丢了 `<>`（`作为你们竞争对手的两个班级都自取灭亡了……你们就算直接把生小凤拿来也能获得胜利。`）。这是 2820 条里唯一的括号缺失，属译者疏漏。
6. **`<Manager?>` 译「经理？」**，是他在复述/确认别人对他的称呼，不是他叫别人"经理"。
7. **不要把短句补全成完整句。** 他的破碎感是角色特征（均中字 16.4 是四人最短）。
8. **不要给他加波浪线、不要加粗话、不要加敬语体系。** `~` 0.0、`本人` 0.0、`您` 0.0。
9. **`Sinners` → 罪人 / 罪人们**（glossary 实测 `Sinners → 罪人` 3763 次）；`The Golden Bough` → 金枝；
   `Abnormality` → 异想体；`Ordeal` → 考验；`Distortion` → 扭曲。

## 翻译操作清单（Do / Don't）

**Do**

- 保留 `< >` 包裹，中文标点写在内部。
- 英文句首 `Oh/Ah` → 「啊」，`Huh/Hmm` → 「嗯」，`Well/Then` → 「那 / 那么」，`Wait` → 「等等 / 等一下」。
- 决策句用「好吧……」「那么……」「总之……」「……吧」起手或收尾。
- 称呼照抄全名：浮士德 / 堂吉诃德 / 良秀 / 希斯克利夫 / 辛克莱 / 默尔索 / 鸿璐 / 李箱 / 格里高尔 / 以实玛利 / 奥提斯 / 维吉里乌斯。
- `■` 按原文保留数量。
- 集体称呼用「罪人们」（其他人多用"大家"，这是他的识别标记）。
- `단테2` 文件里适度提高「我们」「吧」的密度。

**Don't**

- ✗ 把旁人的台词（`钟表头` / `经理`）误当成但丁独白，或反之给旁白加 `<>`。
- ✗ 把 `<>` 换成 `〈〉`「」或省略。
- ✗ 用昵称（小浮 / 以实 / 格雷格 / 维吉）称呼队友。
- ✗ 给 `■` 补出真实词义。
- ✗ 把短句扩写成完整长句。
- ✗ 加 `~`、「呢」、「啦」等轻佻语气词，或加「本人 / 在下 / 您」等敬语。
- ✗ 把 `<Manager?>` 理解成但丁在称呼别人。
