# 机制文本句式模板（英 → 中）

来源：`tools/mine_phrases.py` 对全部 **162,463 组官方英中对照**做句式归一化后统计得出的高频模式。
原始数据：`terms/phrase_patterns.tsv`（前 600 模式）、`terms/_phrase_samples.jsonl`（前 300 模式的实例）。

## 1. 五条最高频模板（覆盖绝大多数技能/被动描述）

| 频次 | English 模式 | 中文固定说法 |
| ---: | --- | --- |
| 3696 | `[Tag] Inflict <N> [Status]` | `[Tag] 使目标增加<N>级<状态>强度` |
| 1462 | `[Tag] Inflict +<N> [Status] Count` | `[Tag] 对目标施加<N>层<状态>` |
| 609 | `[Tag] Inflict <N> [Status] next turn` | `[Tag] 下回合对目标施加<N>层<状态>` |
| 435 | `[Tag] Gain <N> [Status]` | `[Tag] 使自身增加<N>级<状态>强度` |
| 428 | `[Tag] Gain +<N> [Status] Count` | `[Tag] 使自身获得<N>层<状态>` |

实例（`BattleKeywords.json` 等）：
```
EN: [OnSucceedAttack] Inflict 2 [Sinking]          → CN: [OnSucceedAttack] 使目标增加2级沉沦强度
EN: [OnSucceedAttackHead] Inflict +1 [Sinking] Count → CN: [OnSucceedAttackHead] 对目标施加1层沉沦
EN: [WhenUse] Gain 2 [Breath]                       → CN: [WhenUse] 使自身增加2级呼吸法强度
EN: [WhenUse] Gain +2 [Breath] Count                → CN: [WhenUse] 使自身获得2层呼吸法
```

### ⚠️ 最关键的一条：`Potency` 与 `Count` 的措辞完全不同
英文用同一动词 `Inflict/Gain`，中文必须分流：

| 英文 | 中文 | 含义 |
| --- | --- | --- |
| `Inflict N [X]` | `使目标增加**N级**[X]**强度**` | 加的是 **Potency（强度）** |
| `Inflict +N [X] Count` | `对目标**施加N层**[X]` | 加的是 **Count（层数）** |
| `Gain N [X]` | `使自身增加**N级**[X]**强度**` | 自身强度 |
| `Gain +N [X] Count` | `使自身**获得N层**[X]` | 自身层数 |

**注意动词分工**：`Inflict` 对敌方 → `使目标…` / `对目标施加…`；`Gain` 对自身 → `使自身…` / `使自身获得…`。
「增加…级」配「强度」，「施加/获得…层」配层数——**不可混用**。

## 4. 使用方式

1. 拿到英文机制文本，先在此表比对**句式骨架**（把数字/标记替换成占位符）。
2. 命中模板 → 按固定说法套用；状态名以 `terms/术语表.md` 为准。
3. 未命中 → 参考 `terms/phrase_patterns.tsv`（600 条）或 `terms/_phrase_samples.jsonl`（带 8 组实例）找最接近的模式。
4. 方括号 `[X]`、`{}` 占位符、`<style=...>` **原样保留**；**方括号内若是人名等显示文本则要翻译**（如 `[Hong Lu]`→`[鸿璐]`）。详见 `workflow/翻译流程.md` §4.1。
5. 交付前跑 `python3 tools/qa_check.py <en> <cn>` 校验标记与长度。
