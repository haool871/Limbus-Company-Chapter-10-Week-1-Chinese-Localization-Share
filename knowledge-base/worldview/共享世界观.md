# Project Moon 共享世界观专名对照与设定术语指南

> **适用范围**：《Limbus Company》（边狱公司）新文本的中译。
> **前提**：Project Moon 三作共享同一世界观——《Lobotomy Corporation》= **脑叶公司**、
> 《Library of Ruina》= **废墟图书馆**、本作 = **边狱公司**。前两作的专名会在新剧情里
> 大量客串，中译**必须与零协会既有译法一致**。
>
> **证据规则**：下表每一条都给出 `EN | CN | KR | 来源文件`。
> 来源文件均为工作区语料中的**逻辑文件名**（四语按 `id` 对齐），
> 可随时用 `python3 tools/pm_lib.py show <文件名>` 复核。
> 凡语料中查无实证者一律标注 **（待考）**，不做臆造。
>
> 语料口径：`cn` = 零协会汉化包（LLC_zh-CN），`kr` = 官方韩文原文，`en` = 官方英文基准。
> 需要新查时优先用本目录工具：
> ```bash
> python3 tools/pm_lib.py show StoryTheaterDanteNote_11   # 四语对照
> python3 tools/align_index.py probe 'Nursefather'         # 跨文件扫英文
> ```

---

## 0. 三条硬规则

1. **术语表 > 语料 > 推测**。任何专名先在 `terms/glossary.tsv` 查，再 `grep` 语料确认，最后才自拟。
2. **同一专名全篇一致**。同一 `id` 的译名在数百个剧情文件中反复出现。
3. **以英文版为基准文本，不要从韩文直译**。韩文只用于**反查确认**（尤其是英文被本地化改写过的人名/地名）。

## 5. 高频「易错点」清单

1. **The Ring → 环指**（不是「无名指」）；The Middle → 中指；The Pinky → 小指。
2. **Shi Association → し协会**（日文平假名）；**Liu → 六协会**；**Hana → 하나协会**；
   **Devyat' → Девять协会**；**Öufi → Öufi协会**（保留变音符）。其余协会保留拉丁原名。
3. **Thread → 纺锤**（不是「线」「丝」）；**Binding → 纽带**（不是「束缚」）；**Attunement → 感应度**。
4. **Nursefather → 父辈**，**Apprentice → 子辈**（五指通用，不要译「护士长」「学徒」）。
5. **同一层级在不同手指有不同译名**：通用 `Nursefather → 父辈`、`Apprentice → 子辈`；
   但环指另设 `Docent → 讲解员`、`Student → 学徒`、`Maestro → 大师`，食指另有 `Proxy → 代行者`、`Proselyte → 苦行者`。
   **按所属手指选词，不可把环指的 `Student`(学徒) 与通用的 `Apprentice`(子辈) 混用。**
6. **LCA/LCC/LCD/LCE/LCB/LCCB/LCCA 一律保留英文缩写**，首次出现可补中文职能。
7. **Sephirot 名保留英文**（Malkuth、Yesod…），但 **Angela → 安吉拉**、**Hohenheim → 霍恩海姆**。
8. **Wings**：作设定词是「翼」，作专名后缀是「公司」。
9. **E.G.O** 全大写下标点照抄，中文里**不加空格**（`E.G.O装备`、`绽放E.G.O`、`脑叶公司E.G.O::狐雨`）。
10. **`::` 双冒号**是人格/E.G.O 命名分隔符，中译原样保留（`绽放E.G.O::山茶花`）。
11. **危险等级 ZAYIN/TETH/HE/WAW/ALEPH 及异常编号 O-01-04 保留原文**。
12. **Uncategorized → 目前难以分类**（图鉴标签，照抄）。
13. **扭曲现象分期**：初期 / 中期 / 末期（`Early/Middle/Late`），`Incubation`（潜伏期）见 `DanteNoteDetail_175`。
14. **`心` 与 `Shin (心)`**：正文叙述用「心」，术语栏用 `Shin (心)`；`心-地慧星` 这类复合名不加空格。
15. **`都市` 的「区」用阿拉伯数字 + 区**（`11区`、`District 14` → `14区`）。
