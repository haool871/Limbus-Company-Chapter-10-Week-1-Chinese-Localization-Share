## 🚩 开始翻译前必读（5 条铁律）

1. **术语表优先**：任何专名先查 `terms/术语表.md`（或 `terms/glossary.tsv`），再 `grep` 语料确认既有译法，最后才自拟。
2. **方括号分两类**：拉丁标识符（`[Vibration]`、`[OnSucceedAttack]`）**原样不译**；人名/状态名（`[Hong Lu]`→`[鸿璐]`）**必须翻译**。
3. **中译跟韩文不跟英文**：官方英文系统性丢弃韩文敬称（辛克莱 62%、以实玛利 68%），**从英文转译必须主动补回「先生/小姐/女士」**。
   ⚠️ 例外：韩文 `군`（小称）与英文 `young X` 一样**丢掉不译**。**表尊敬的补，表"你比我小"的不补。**
4. **机制文本套模板**：`Inflict N [X]`→`使目标增加N级[X]强度`；`Inflict +N [X] Count`→`对目标施加N层[X]`。见 `style/机制句式模板.md`。
5. **交付前跑质检**：`python3 tools/qa_check.py --official <文件名>`；口吻相关再跑 `tools/check_speech_context.py`。

> 📌 **改文件的铁律**：不要手写/正则清洗 JSON。走 §7.0 译文表流水线，或逐字段精确赋值；
> 改前备份、改后逐条 diff。**批量操作最常误伤 `title`/`teller`/`place` 等列**（见 SOP §5.9b）。

## 工具（`tools/`）

```bash
# ── 查询（最常用）────────────────────────────
python3 tools/pm_lib.py show StoryData/1D101A.json   # 四语按 id 对照

python3 tools/pm_lib.py grep 事务所 -l cn            # 在指定语言搜文本

# 跨文件正则扫描（更快，直接拿 CN/KR）
python3 tools/align_index.py probe "Inflict \d+ \[Sinking\]"

# ── 质检 ────────────────────────────────────
python3 tools/qa_check.py --official StoryData/S709B.json
python3 tools/qa_check.py en.json cn.json

# 口吻：自称/称呼是否符合零协既有习惯（--table 只打印分布表）

# 术语：有没有把零协已翻过的词自创成别的写法
python3 tools/check_established_terms.py

# 成品验收：结构/标记/占位符/译出率 逐一对比英文源
python3 tools/verify_output.py

# ── 重建语料（一般不必跑）────────────────────
python3 tools/pm_lib.py build          # 重建文件索引
python3 tools/export_corpus.py         # 重导 686k 行语料
python3 tools/analyze.py all           # 说话人/词频/术语校验
python3 tools/voice_profile.py         # 文风量化画像
python3 tools/rank_terms.py            # 术语频率加权
python3 tools/mine_phrases.py          # 句式模板挖掘
python3 tools/resolve_citations.py --all  # 展开 @@model|file|id@@ 引用
```

### 性别中立职称（照搬英文会错）
五指 `아비` → EN `Nursefather` → CN **父辈**（弟子＝**子辈**）。这是**性别中立**的职称：拇指父辈 Valencina 是**女性**。韩文用中性 `그자/저자`，英文擅自选了 he/she，中文需在「她／他／那个人／那家伙／姓名」之间按语境三选一——**照搬英文的「她」是错的**。
贾丘/孔丘**从不使用性别代词指人**（EN `Hurry her ascension` → CN `加快家主的任命`）。
