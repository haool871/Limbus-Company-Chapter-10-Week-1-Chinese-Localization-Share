# 翻译知识库索引

本项目用于《Limbus Company》的中文增量汉化：保存当前版本基线，游戏更新后比较官方原文，再处理本轮未被适用汉化覆盖的内容。

**当前处于等待更新状态，没有活动翻译批次，也没有预设修改源。** 机器状态见 `project.json`；说明见 [当前状态](当前状态.md)。上一轮补丁已归档，不作为下一轮默认任务。

知识库根目录下常用命令：

```bash
python3 tools/doctor.py
python3 tools/batch.py status
python3 tools/pm_lib.py find <文件关键字>
python3 tools/pm_lib.py grep <术语> -l cn
python3 tools/ctx_dump.py <逻辑文件名> --out out/context.txt
```

游戏更新后才运行：

```bash
python3 tools/snapshot.py capture --name <新版本快照名>
python3 tools/scope.py --new snapshots/<新版本快照名> --save out/update_scope.json
```

后续批次建立、编辑、验收、回滚和交付参数见版本更新流程。查询默认采用已记录基线；指定其他版本可设置 `LIMBUS_SNAPSHOT`。范围扫描不提供新快照时不会生成任务。

## 数据与工具边界

- `snapshots/`：带文件集合与哈希的原始版本快照；用于增量判断，不可原地修改。
- `batches/`：仅确定本轮范围后建立的活动批次；当前没有批次。
- `archives/`：历史补丁、旧规则与已完成批次，不能自动恢复为修改源。
- `data/corpus.jsonl`、`data/_align.pkl`：可再生检索缓存，不能代替版本快照。新版保留记录类型与重复出现序号，歧义记录不跨语言自动配对。
- `out/`：报告、上下文及本地交付物，不是默认译文真源。
- 旧 TSV 写入命令和旧补丁合并方式已退役，详见主流程；不要靠建立空 `patch_v2/` 获得“0问题”。

结构检查、术语线索与人工语义审校各有边界。零疑点不代表语义正确，JSON合法不代表游戏加载一定成功。
