## 4. 零协的翻译倾向（供下次借鉴）

从 6,485 处差异看，零协与我的系统性差异有四个方向：

1. **词汇更「直给」**：`FOMO`→错失恐惧症、`L'Inamovible`→不可动摇者（不保留外文）
2. **句更短**：`向内蜷缩。再深一些。再紧一些。让外壳在残余之物周围硬化。`
   → **`就这样僵硬地向着内侧蜷缩起来。`**（合并成一句）
3. **不照英文的修辞扩写**：`Le Noir的精纺毛料如铠甲般包裹身体，以坚实而不变形的轮廓修饰穿着者的身形。`
   → **`黑派面料通过如同铠甲般坚固稳定的形态来修饰客人们的体型。`**
4. **保留口语碎片**：`按静！按静！`（我作「闭嘴！闭嘴！」）、`从皮里出去！`（我作「蜕下这层皮！」）
