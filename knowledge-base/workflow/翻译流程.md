# 翻译流程

现行流程见 [版本更新流程](版本更新流程.md)。本文件只保留翻译原则，不再另维护一套批次、写回或发布命令。

- 当前没有活动批次时，只有参考资料和版本快照，没有待修改译文目录。
- 游戏更新后先比较新旧官方原文，处理本次新增、变更、删除与结构变化；历史缺口另列。
- 翻译单位是对话回合或 RPG 对话组，写回单位是批次清单中的完整字段路径。
- 语义按实际源文，韩文优先；术语、角色口吻、机制句式参考已核实的零协用法。
- 先做语义审校，再做通读润色；记录只绑定实际审阅过的当前译文。
- 有效继承的上游字段受保护；其历史语义疑点另列。原文发生变化时，旧上游非空译文须重新判断是否适用，不能一律保留，也不能自动视为已更新。
- 引擎标记、占位符和目标结构保持完整。显示用方括号与引擎标记不同，例外须在批次决策中记录。
- 不用正则清洗 JSON，不用 id 字典覆盖重复记录，不把上下文中的位置直接当 id。

参考资料：[重译手册](重译手册.md)、[通读润色手册](通读润色手册.md)、[与零协差距教材](与零协差距教材.md)、[新版译名映射](零协新版译名映射.md)。它们的历史统计是翻译参考，不是当前批次范围或强制改动数量。
