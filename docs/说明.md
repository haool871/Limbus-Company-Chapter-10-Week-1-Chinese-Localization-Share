# 安装说明（详细版）

本补丁为《Limbus Company》第十章第一周内容的个人 AI 汉化补丁。
本文只讲**怎么装**，不涉及翻译原理。

---

## 📌 一句话说清怎么装

> ### 把 `patch` 里的东西**全选**，**放到** `LimbusCompany_Data/Lang/LLC_zh-CN/` **下**，弹窗选**覆盖**。

本文其余内容，就是把这句话拆开细说 + 排错。

---

## 一、先搞清楚：这是补丁，不是汉化包

| | 是什么 | 从哪来 |
| --- | --- | --- |
| **零协会汉化包** | 完整的汉化（游戏绝大部分文本 + 中文字体 + 语言选项） | 官方：<https://www.zeroasso.top/docs/install/install> |
| **本补丁**（`patch`） | 只补零协会**还没做**的第十章新内容 | 本仓库 |

**所以必须按顺序：先装零协会包，再放本补丁。**

判断零协会包是否已装好：游戏目录里有没有 `LimbusCompany_Data/Lang/LLC_zh-CN/` 这个文件夹。

---

## 二、找到游戏目录

1. 打开 Steam
2. 进「库」，找到 **Limbus Company**
3. **右键** → **管理** → **浏览本地文件**

会弹出一个文件夹，里面能看到：

```
Limbus Company/
├── LimbusCompany.exe
├── LimbusCompany_Data/     ← 要进这个
└── ...
```

---

## 三、进入 `Lang/LLC_zh-CN`

在游戏目录里依次双击进入：

```
LimbusCompany_Data  →  Lang  →  LLC_zh-CN
```

到达后地址栏看起来类似：

```
…\steamapps\common\Limbus Company\LimbusCompany_Data\Lang\LLC_zh-CN
```

**这个 `LLC_zh-CN` 文件夹，就是补丁要放进的地方。**

> 如果 `Lang` 或 `LLC_zh-CN` 不存在 → 说明零协会汉化包还没装好，回第一步。

---

## 四、全选 → 放到 LLC_zh-CN 下 → 覆盖（关键步骤）

### 4.1 先看清 `patch` 的结构

```
patch/
├── Announcer.json               ┐
├── BattleKeywords.json          │
├── BattlePass-a1c10.json        │
├── ……                           │  散装 json 文件，共 61 个
├── Skills_personality-04.json   │
├── Skills_personality-08.json   ┘
├── RPGSystem/                   ┐
├── StoryData/                   │  文件夹，共 4 个
├── PersonalityVoiceDlg/         │
└── BattleAnnouncerDlg/          ┘
```

**看到几十个文件不要慌，也不用挑。全选复制就行：全选 → 放到 `LLC_zh-CN` 下 → 覆盖。**

### 4.2 三步搞定

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| **① 全选** | 打开 `patch` 文件夹，按 **Ctrl + A** | 文件和文件夹一起选中 |
| **② 复制** | 按 **Ctrl + C** | — |
| **③ 放到 LLC_zh-CN 下并覆盖** | 进到第三节的 `LLC_zh-CN` 文件夹，按 **Ctrl + V**，弹窗选 **「替换目标中的文件」** | 会覆盖 120 个文件，其中大部分内容与零协最新版**相同**，正常现象 |

**Linux / Steam Deck**：在 `patch` 所在目录执行

```bash
cp -r patch/. "/你的路径/steamapps/common/Limbus Company/LimbusCompany_Data/Lang/LLC_zh-CN/"
```

### 4.3 检查是否装对

回到 `LLC_zh-CN` 文件夹，**必须能看到这两个文件夹**：

```
LLC_zh-CN/
├── RPGSystem/      ← 必须有
├── StoryData/      ← 必须有
├── Font/
├── Info/
├── ……
└── 一堆 json 文件
```

- ✅ **有** `RPGSystem` 和 `StoryData` → 装对了
- ❌ **没有** → 说明第 4.2 步只复制了散装文件，文件夹漏了。重做一遍，注意 `Ctrl+A` 要选中文件夹

---

## 五、启动游戏

直接启动即可。**不需要**在游戏里重新选语言。

如果进游戏后发现语言不对，在主界面**左下角从左往右第二个按钮**里选 `LLC_zh-CN`（只需设置一次）。

## 六、验证是否生效

装好后，以下位置应该显示中文：

| 位置 | 看什么 |
| --- | --- |
| **商城 / 编队** | 良秀 · 黑派制鞋馆、以实玛利 · 红派精品店 的**技能名与描述** |
| **迷宫** | 西西弗百货 1F–4F / B1–B2 的对话与道具 |
| **主线** | 第十章 S1000B 开头的商场广播 |

只要有一处显示英文或韩文，把截图发出来即可定位。

## 七、卸载

| 需求 | 做法 |
| --- | --- |
| **彻底删汉化** | 删掉整个 `Lang` 文件夹 |
| **只撤本补丁** | 删掉零协**没有**的那 9 个文件（`StoryTheaterMain-a1c7p1.json`、`UserBanner-a1c7p3/a1c8p1.json`、`UserTicket-EGOBg/L/R-a1c7p3/a1c8p1.json`），再用零协包覆盖一遍即可。其余文件内容与零协一致，删不删都一样 |
| **恢复游戏原状** | 删掉 `Lang` 文件夹即可，游戏会回到韩 / 英 / 日原版 |

## 八、常见问题

**Q1：`patch` 里几十个文件，我要挑着装吗？**
不用。**全选（Ctrl+A）→ 放到 `LLC_zh-CN` 下 → 覆盖**，一个都不能少。文件多是因为第十章内容多。

**Q2：为什么还要先装零协会汉化包？**
本补丁只包含第十章新增内容。游戏的其余文本、中文字体、语言下拉选项都来自零协会的包，缺了会显示异常。

**Q3：装完还是英文？**
按顺序排查：
1. `LLC_zh-CN` 里有没有 `RPGSystem`、`StoryData` 两个**文件夹**（最常见的漏步）
2. 游戏内语言是否选了 `LLC_zh-CN`
3. 是否重启了游戏（装补丁时游戏要关掉）

**Q4：会不会封号 / 有风险？**
本补丁只往游戏目录里放文本文件，不修改游戏程序、不联网、不影响存档。零协会的官方接口本身也被月亮计划认可。

**Q5：更新游戏后补丁还在吗？**
- 游戏小更新：文件通常保留。
- 游戏大更新或「验证游戏文件完整性」：可能被重置，重新复制一遍 `patch` 即可。

**Q6：字体显示成方块？**
说明中文字体没装。零协会包里的 `LLC_zh-CN/Font/Context/ChineseFont.ttf` 需要存在（本补丁不含字体，字体由零协会包提供）。
